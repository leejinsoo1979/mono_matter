# monogram

첨부된 monogram 로고를 사용하는 재료·제품 작업 공간입니다. 공개 랜딩, 제품 카탈로그, 무한 캔버스, 3D 재료 편집기, 사양표, 프로젝트·라이브러리 관리, 계정과 SQLite 저장 서버를 포함합니다. 원본과의 전체 기능 동등성이 목표이지만, 모든 화면과 사용 결과가 동일하다고 검증된 릴리스는 아닙니다.

## 실행

Node.js 22 이상에서 실행합니다.

```sh
npm install
npm run dev
```

monogram 전용 포트는 화면 `5188`, API `4388`입니다. mmmcraft가 사용하는 `5173`·`5174`와 분리하며, 화면 포트가 이미 사용 중이면 다른 포트로 넘어가지 않고 실행을 중단합니다.

첫 화면은 공개 랜딩 [http://127.0.0.1:5188/](http://127.0.0.1:5188/)이며, 작업 공간은 [http://127.0.0.1:5188/catalog](http://127.0.0.1:5188/catalog)입니다. `/landing`은 랜딩의 별칭이고 `/products`, `/app`은 카탈로그 진입 경로입니다. API는 http://127.0.0.1:4388 에서 실행됩니다. 로컬에서는 카드 없이 방문자 작업 공간을 만들 수 있습니다. 이메일 계정의 최초 생성 시 방문자 자료를 승계하며, 비밀번호와 세션은 인증 서버에서 처리합니다. SQLite와 업로드는 Git에서 제외된 `runtime/`에 저장됩니다.

## 공개 랜딩과 진입 경로

처음 빠져 있던 공개 랜딩을 추가했습니다. `/`와 `/landing`은 작업 공간을 생성하거나 작업 공간 API 응답을 기다리지 않고 렌더합니다. 원본 공개 HTML에서 관찰한 35개 제품 부유 이미지와 소개 자산을 사용하며, 제품·브랜드 검색, 카테고리, 기능 소개, 작업 공간으로 연결합니다. 확보한 랜딩 자산은 총 46개이며 출처·크기·SHA-256을 기록했습니다. 원본 스크롤 연동 애니메이션이나 픽셀 단위 동일성까지 검증한 것은 아닙니다.

`/login`은 로그인, `/signup`과 `/register`는 실제 계정 생성 폼을 엽니다. 검색어·제품·분류와 작업 파일의 진입 경로를 인증 후에도 유지하며 외부 주소로의 `returnTo`는 거부합니다. 원본 데스크톱 가입 팝업을 그대로 복제한 구성은 아닙니다.

소개 페이지는 `/material-board`, `/schedule`, `/material-samples`·`/virtual-samples`, `/pricing`, `/virtual-showroom`, `/about`, `/articles`, `/request-demo`에서 열립니다. 보드·사양표·공급사 소개의 CTA는 실제 작업 공간 기능으로 연결합니다. `/request-demo`는 제품 찾기·보드·사양표의 미리보기 탭과 작업 공간 CTA를 제공하며, 원본 영업 문의 제출·상담 예약 서비스가 연결되지 않았음을 표시합니다. 원본 Contact us 폼과 외부 전송은 구현·연결하지 않았습니다.

원본 고객사 로고와 후기를 monogram의 고객 실적으로 사용하지 않았습니다. 현재 카탈로그에 있는 브랜드와 직접 작성한 9개 작업 가이드로 대체했습니다. `/privacy`·`/privacy-statement`와 `/terms`·`/terms-of-use`는 원본 법률 원문을 복사한 문서가 아니라 현재 로컬 설치의 저장·공유·연동 범위를 설명하는 preview notes입니다. Cookie settings는 실제 모달로 열리고 Escape로 닫힙니다. 광고·분석 추적 서비스와 선택적 동의 수집은 설정하지 않았습니다. 랜딩은 현재 영어만 제공하며 원본의 중국어 경로는 복제하지 않았습니다.

## 편집과 저장

현재 원본의 Board는 제품·이미지를 배치하는 무한 2D 캔버스입니다. 로컬 앱은 이를 기본으로 하며, 과거 공식 3D 데모에 대응하는 별도 3D 모드도 제공합니다. 두 모드는 같은 보드 데이터를 사용합니다. 텍스트·이미지·화살표·스케치·댓글, 레이어, 잠금, 변환, undo/redo, 미니맵·줌과 PNG 출력을 지원합니다. 3D 모드에서는 실제 메시, 재질 맵, PBR 속성, 조명·배경과 카메라를 조절합니다. 원본 최신 화면과 과거 녹화 데모를 동일한 편집기로 취급하지 않습니다.

여러 창의 편집은 revision 확인, ID별 병합과 SSE를 거쳐 저장됩니다. 원격 변경이 오면 이전 편집 기록과 진행 중 제스처를 정리하고, 자체 저장 응답은 undo 기록을 유지합니다. 저장 실패는 화면에 표시하고 재시도합니다. 완전한 오프라인 저장·재접속 복구를 보장하는 구성은 아닙니다.

사양표는 제품·속성 열, 그룹, 상태, 합계, 구성 프리셋과 CSV/PDF 출력을 지원합니다. 프로젝트와 라이브러리는 이름·복제·제품 구성·보관·복원 등의 관리 기능을 제공합니다.

## 공유와 공급사

보드·사양표 공유에는 보기, 고객 승인, 편집 권한이 있습니다. 프로젝트·라이브러리에도 범위가 제한된 보기·편집 링크와 철회 기능이 있습니다. 공유 데이터와 업로드는 해당 리소스의 제품 범위로 제한됩니다. 라이브러리 사본은 제품과 파일을 독립적으로 보존합니다. 이 링크 방식이 원본의 모든 이메일 초대·조직 역할·가입·탈퇴 흐름을 재현했다는 의미는 아닙니다.

`/supplier`에서 로컬 공급사 프로필, 제품·사양·변형·파일, 컬렉션과 프로젝트 갤러리를 관리합니다. 공개한 쇼룸은 `/showroom/:slug`에서 로그인 없이 열립니다. 공개 데이터에는 비공개 연락처·메모·초안·리드가 포함되지 않습니다. 쇼룸 요청은 실제 공급사 리드로 저장되고, 답장은 요청자의 monogram 알림함으로 전달됩니다. 수동으로 추가한 리드의 후속 내용은 기록만 하며 외부 메일 발송으로 표시하지 않습니다.

공급사 콘솔은 이 설치 안에서 작동하는 기능입니다. 원본 공급사 네트워크 가입·승인, 외부 공급사 디렉터리 라우팅, 실제 견적 회신이나 물리 샘플 배송은 연결·검증하지 않았습니다. 일반 카탈로그의 요청은 내부 기록과 알림으로 저장하며, 메일을 설정하면 지정된 운영 수신함으로 전달합니다.

공유 URL은 기본적으로 로컬 주소입니다. 다른 기기에서 사용하려면 호스팅과 `APP_URL`, 인증 URL, 운영 환경 구성이 필요합니다. 공개 배포는 수행하지 않았습니다.

## 제품과 3D 근거

현재 번들은 직접 관찰한 공개 제품 47개와 그 제품들의 공식 공개 API가 명시한 변형 398개를 합친 **445개 SKU**입니다. 사양·갤러리·변형 식별자·제공 파일·PBR 맵을 원본 응답에서 가져왔으며, API 기반 자산 1,036개의 출처와 해시를 기록했습니다. 전체 원본 제품 DB를 확보한 것은 아닙니다. 가격을 제공하지 않은 제품은 견적 요청 대상으로 표시합니다. 긴 제품 소개문 대신 사실에 근거한 짧은 설명과 원문 링크를 사용합니다.

**412개 SKU가 서로 다른 원본 GLB 25개를 공유하며, 33개 SKU는 원본부터 이미지 평면 샘플입니다.** F300은 원본 API의 `isUseAlphaPlane=true`, `modelUrl=null`인 평면 이미지 참고 자료이며, 실제 의자 메시를 가진 것으로 표시하지 않습니다. 모델이 없는 제품에 원본 3D를 확보했다고 주장하지 않습니다.

Draco 압축 GLB, 원본 PBR·ORM·노멀·투과 맵, 맵별 반복과 degree 회전, 원본 HDR을 사용합니다. 원본 `target` 재질에는 외부 PBR을 적용하고 다른 내장 재질은 보존합니다. 사용자 모델의 원래 재질과 수동 수정도 구분합니다. 모델 비율과 중첩 변환을 유지하며 카메라를 실제 경계에 맞춥니다. 동일한 모델·HDR을 사용해도 조명·카메라·렌더 결과의 픽셀 단위 동일성을 인증한 것은 아닙니다.

기존 작업 공간에는 보수적 동기화를 적용합니다. `Settings → Account → Back up & refresh catalog`는 백업을 내려받은 뒤 확보된 원본 카탈로그를 명시적으로 복구합니다. 사용자 제품, 프로젝트, 즐겨찾기와 라이브러리 선택을 보존합니다.

근거는 다음 파일에 분리되어 있습니다.

- `reference/asset-provenance.json`: 최초 47개 카드의 브라우저 자산 묶음.
- `reference/api-enrichment-provenance.json`: 445개 SKU의 API·변형·파일·PBR 출처와 1,036개 자산 해시.
- `reference/environment-provenance.json`: 원본 HDR 주소와 검증한 SHA-256.
- `reference/landing-audit.json`: 공개 랜딩의 11개 구역, 메뉴·CTA·정책·문의 목적지 조사.
- `data/landing-assets.json`, `reference/landing-assets-provenance.json`: 랜딩 자산 46개의 사용 목록과 원본 URL·해시. 원본 고객사 로고와 후기는 제외.
- `reference/current-free-audit.json`: 공개 화면, 실제 Free 계정 관찰, 공개 코드와 미확인의 구분.
- `reference/feature-parity.json`: 기능별 로컬 구현·검증·원본 비교 상태.

공개 API를 다시 조회하려면 `node scripts/enrich-reference.mjs`를 실행합니다. `--cache-only`는 기존 응답과 자산만 사용하며 캐시가 빠졌으면 결과를 덮어쓰기 전에 중단합니다. 원본 ID를 추측하거나 전체 번호를 순회하지 않습니다.

## 계정·요금제와 외부 서비스

프로필·공개 여부·아바타, 계정 비밀번호 추가·변경, 신청 내역과 Light/Dark/System 테마를 저장합니다. 공개 프로필은 프로젝트를 자동 공개하지 않습니다. 디자이너·교육·Enterprise 신청은 제출 상태로 저장되며, 실제 심사 승인이나 할인 권한을 자동으로 부여하지 않습니다.

Free/Starter/Plus의 프로젝트·라이브러리·저장 자산 한도, 디자이너 인증 예외, 일일 크레딧과 출력 워터마크 정책을 로컬에서 적용합니다. 원본의 정확한 10일 체험·500 크레딧·갱신 알림 흐름은 완성하지 않았습니다. 원본 공개 가격표의 **Studio는 Coming soon**입니다. 현재 Free 설정에서는 Team, Personal access token, SketchUp 항목이 보이지 않았습니다. 공개 코드에 존재하는 플래그만으로 실제 활성 기능이라고 판정하지 않습니다. Style Passport와 모든 유료·공급사 역할 화면도 전수 확인하지 못했습니다.

`.env.example`에는 AI, Google, 메일, Stripe, Pinterest 설정 예시가 있습니다. 비밀 값은 저장소에 넣지 않으며 서버 실행 전에 환경 변수를 설정해야 합니다. 미연결 기능은 성공으로 표시하지 않습니다.

AI는 설정된 HTTP 이미지 서비스의 성공 결과만 저장하고 크레딧을 차감합니다. Stripe는 서명된 이벤트와 공급자의 구독·청구서 확인 뒤 권한과 월 크레딧을 갱신합니다. Pinterest는 계정에 묶인 OAuth, 서버 암호화 자격 증명, 갱신·페이지 탐색·선택한 핀 가져오기·중복 방지·연결 해제를 구현했습니다. 실제 외부 계정으로 AI 생성, 메일 발송, Google/Pinterest 승인, 청구를 실행한 결과는 아직 검증하지 않았습니다. 원본 Matter AI의 모델·에이전트·생성 품질과 동일하다고 주장하지 않습니다.

## 검증과 Web Clipper

```sh
npm run build
npm test
npm run test:clipper
```

API·SQLite·권한·동시 수정·카탈로그 동기화·재질·카메라 검증과 브라우저 확인을 구분해 기록합니다. 최종 실행 결과와 남은 범위는 `reference/feature-parity.json`에 있습니다. 브라우저 증거는 `artifacts/`에 있으며, 일부 화면은 격리된 검증용 데이터로 촬영했습니다. 실제 3D 보드의 PNG 다운로드는 Blob 방식으로 수정한 뒤 파일 생성과 4개 배치 항목을 확인했습니다. 검증 파일 `artifacts/monogram-3d-export-1200px.png`는 1200×1334, 206,539바이트이며, 수정 전 실패와 수정 후 근거를 조사 JSON에 함께 기록했습니다.

랜딩 추가 후 전체 자동 테스트는 **76/76** 통과했습니다. 여기에는 인증 복귀 경로·외부 redirect 차단·공개 페이지 분기 검증 3개가 포함됩니다. Web Clipper 4개는 이전의 별도 실행입니다.

최신 카탈로그 화면 자산 교체 후 최종 타입·Vite 빌드도 통과했습니다. `dist`만 별도 정적 서버에서 제공한 새 브라우저 첫 진입에서 랜딩·35개 hero 제품을 확인했고, 깨진 이미지·콘솔 오류/경고·API 요청은 모두 0건이었습니다.

브라우저에서는 35개 hero 이미지와 깨진 이미지 0개, `Ceragni` 검색의 카탈로그 전달·192개 결과, 가입 폼 진입, Explore의 workflow 이동, 쿠키 모달·Escape, 390px 화면의 가로 넘침 없음과 모바일 메뉴 열기·Escape 닫기·버튼 포커스 복귀를 확인했습니다. 데모 탭의 방향키 전환·선택 상태와 연간 요금(Free 0, Starter 6, Plus 21, Studio 50 USD/월), Studio Coming soon 비활성 상태도 확인했습니다. 이 확인에서 새 계정을 만들거나 문의·예약·결제를 실행하지 않았습니다.

Web Clipper는 `public/clipper/monogram-clipper.zip` 또는 `extension/`을 사용합니다. 사용자가 추출 버튼을 누를 때 현재 페이지의 제품 정보만 읽고, monogram 제품 검토 화면에서 최종 저장합니다. 설치 방법은 `extension/README.md`를 따릅니다. 확장 프로그램 공개 스토어 배포와 모든 외부 판매 사이트에 대한 추출 동작은 검증하지 않았습니다.
